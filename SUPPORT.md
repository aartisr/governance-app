# Support

## Questions and usage help

For reproducible bugs or feature requests, use the repository's GitHub issue templates. For questions that are not bug reports, start a GitHub discussion if discussions are enabled; otherwise, open an issue with the `question` label.

## Before opening an issue

- Search existing issues and the README.
- Include the steps to reproduce, expected behavior, and actual behavior.
- Remove API keys, personal information, and other sensitive data from logs and screenshots.
- Remember that the project's data and model outputs are illustrative and are not official civic, legal, or policy advice.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
