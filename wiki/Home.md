# Civic Accord

Civic Accord is a civic decision-support **prototype**. It uses fictional bills, district profiles, source excerpts, comments, and scores to demonstrate a review process. It does not connect to an official legislative feed or predict real policy outcomes.

## Start here

1. [Review a sample bill](https://governanceapp.ai-aarti.com/bills).
2. [Compare illustrative district exposure](https://governanceapp.ai-aarti.com/impact).
3. [Explore priority costs](https://governanceapp.ai-aarti.com/feedback).
4. [Compare preset amendments](https://governanceapp.ai-aarti.com/compromise).

For a guided example, read [[How-It-Works]]. Verify any real bill using an authoritative legislative source before discussing its effects.
